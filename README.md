# Crayons First Studios — Frontend + Admin Panel

## Structure
```
crayons-store/
├── index.html          # Storefront
├── css/style.css
├── js/app.js
├── images/logo.png     # Your Crayons Pictures logo
└── admin/index.html    # Admin panel
```

## Features
**Frontend:**
- Hero with logo
- Sections: Equipment Rentals, Studio Booking, Marketplace, E-store
- Product cards with prices (₹)
- Book / Buy buttons (demo alerts)

**Admin Panel:**
- Add products (title, category, price, description)
- View / Delete products
- Data stored in browser localStorage (demo)

## How to Run
1. Open `index.html` in browser
2. Admin: open `admin/index.html` or click Admin link
